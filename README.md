# 4-AI Hub

Статический сайт без сборки: `index.html`, `css/`, `js/`, `assets/`.

## Структура
- `js/providers.js` — узлы (Grok, ChatGPT, Claude, Gemini), идентификаторы моделей, вызовы API
- `js/app.js` — онбординг, проверка ключей, чат, режимы, каскадное переключение
- `css/style.css` — светлый минималистичный интерфейс
- `_headers` — заголовки безопасности для Cloudflare Pages

## Публикация
1. GitHub: создайте репозиторий и загрузите содержимое папки так, чтобы `index.html` лежал в корне.
2. Cloudflare: Workers & Pages, Create, Pages, Connect to Git, выберите репозиторий.
3. Build command оставьте пустым, Build output directory: `/`. Нажмите Deploy.

Названия кнопок в панели Cloudflare могут немного отличаться.

## Ключи и безопасность
Ключи вводятся на сайте и хранятся только в localStorage браузера пользователя. В репозиторий они не попадают. Не вставляйте ключи в файлы проекта.

## Настройка
- Идентификаторы моделей: `MODEL` в `js/providers.js`.
- Значки сетей упрощённые: замените `svg` в `P` на официальные логотипы.
- Число кругов обсуждения и предел вариантов решений: `CFG` в `js/app.js`.
- Если провайдер блокирует прямые запросы из браузера (CORS), направьте вызов через Cloudflare Worker.
