# Изменения проекта

## Обновлённая версия

- Изменена стратегия проверки ключей: каждый провайдер отображается отдельно; ошибки авторизации отличаются от сетевых сбоев и квот.
- Добавлен выбор модели по фактическому списку API и переход к запасной модели при явной ошибке «модель не найдена».
- Добавлена функция-прокси Cloudflare Pages с ограниченным списком маршрутов и лимитом тела запроса.
- Добавлены отмена текущего задания, состояние узлов, лог ошибок и панель результата модели справа.
- Добавлена необязательная тестовая генерация с предупреждением о возможном расходе API-квоты.
- Логотип пользователя вынесен в PNG с прозрачным фоном и анимирован на заставке; подготовлены отдельные изображения четырёх логотипов провайдеров.
- Добавлены автоматические тесты проверки ответов API и маршрутов прокси.
